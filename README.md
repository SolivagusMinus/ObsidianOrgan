# ObsOrg — плагин для Obsidian

Главные файлы папок со ссылками для графа + граф «дерево прокачки» с эффектами + уровни веток + счётчик слов за день + календарь с анимациями.

Создаёте папку `Меню` — внутри сразу появляется файл `Меню.md`.
Кидаете в папку любой файл — в `Меню.md` добавляется ссылка `[[файл]]`.
Удаляете или переносите файл — ссылка исчезает. В графе все файлы папки
связаны со своим главным файлом, а через главные файлы подпапок получается дерево:

```
Меню ── Суп
  │ ─── Салат
  └──── Десерты ── Торт
                └─ Мороженое
```

## Что умеет

- **Автосоздание.** Новая папка → главный файл с тем же именем (имя настраивается: `{{folder}}`, `_{{folder}}`, `{{folder}} (оглавление)`…).
- **Автосписок ссылок** на все файлы папки: заметки, картинки, PDF, canvas (можно ограничить только `.md` или исключить расширения).
- **Раскладки:** столбик (маркированный список), нумерованный список, таблица в 1–6 колонок, свой шаблон строки
  (например `- [ ] {{link}} — {{ctime}}`).
- **Главный файл можно редактировать.** Плагин трогает только блок между
  `%% folder-hub:start %%` и `%% folder-hub:end %%` (в режиме чтения эти метки не видны).
  Всё выше и ниже — ваше. А с включённой опцией «Сохранять ручные правки» можно и внутри
  списка менять порядок строк, дописывать пояснения рядом со ссылками, вставлять подзаголовки —
  плагин лишь допишет новые файлы в конец и уберёт строки удалённых.
- **Связь с подпапками:** в главный файл попадает ссылка на главный файл каждой подпапки.
- **Выделение:** главный файл в проводнике окрашивается выбранным цветом, получает значок (★ по умолчанию)
  и жирный шрифт; заголовок самой заметки тоже окрашен. По желанию подкрашиваются и папки.
- **Цвет в графе:** главные файлы получают тег `#folder-index`; кнопка «Цвет в графе» в настройках выделяет их в графе цветом.
- **Главным можно назначить любую заметку папки**:
  - правый клик по заметке (на телефоне — долгое нажатие) → **«Сделать главным файлом папки»**;
    то же меню открывается правым кликом по узлу в графе и через «⋮» у открытой заметки;
  - правый клик / долгое нажатие по папке → **«Выбрать главный файл…»** — список заметок с поиском;
  - команда «ObsOrg: Папки: сделать текущую заметку главным файлом папки».

  Выбранная заметка получает свойство `folder-index: true`, тег, выделение и автосписок ссылок.
  Прежний главный файл не удаляется: он становится обычной заметкой (`folder-index: false`), из него
  убирается только автосписок — ваш текст остаётся. «Перестать быть главным файлом» — в том же меню.
- Переименовали папку — главный файл переименуется следом (ссылки на него обновятся).
- При запуске Obsidian списки сверяются с реальным содержимым папок (если файлы добавляли
  через проводник ОС, пока Obsidian был закрыт).

## Граф: дерево прокачки

Каждая папка верхнего уровня — **ветка**, которая растёт в свою сторону, как ветки навыков в играх.
Главные файлы папок закрепляются узлами вдоль своей ветки (подпапки — дальше от центра),
а обычные файлы висят на них листьями и живо покачиваются.

- **Форма:** «Звезда» — ветки расходятся во все стороны; «Дерево прокачки» — ветки стоят рядом и растут вверх.
- **Направление каждой ветки** можно задать вручную (↑ ↗ → ↘ ↓ ↙ ← ↖) или оставить «Авто» —
  тогда ветки займут свободные стороны, крупным достанется больше места.
- **Длина ветки** и **ширина веера** — ползунками; **«Закреплять и файлы»** — выстроить файлы аккуратным веером.
- Команда: «Граф: включить/выключить дерево прокачки».

> Раскладка использует внутренний механизм графа Obsidian (тот же, которым граф закрепляет узел,
> пока вы его тащите). Официального API для этого нет, поэтому после обновления Obsidian эффект может
> перестать работать — заметкам это ничем не грозит, тогда просто выключите опцию и напишите, обновим плагин.
> Работает в глобальном графе; локальный граф не меняется.

## Граф: эффекты

Рисуются поверх графа на прозрачном слое; сам граф не меняется. Работают и в локальном графе.

- **Импульс от главных файлов** — цвет и интервал (1–20 с) настраиваются:
  - **кольцо** расходится от главного файла;
  - **лучи по связям** — бегут от главного файла к его файлам и подпапкам, а дальше подпапки
    «загораются» по очереди, всё глубже по ветке. Четыре вида:
    **Искра** (светящаяся точка), **Луч** (лазер с белым концом и затухающим хвостом),
    **Энергия** (волнистый поток плазмы с бегущими сгустками), **Электричество** (мерцающая молния
    с боковыми разрядами). Режим — «По импульсу» (волной с интервалом) или «Постоянно»; толщина настраивается;
  - **свечение** — главные файлы мягко «дышат» светом.
- **Анимация связей**: «Статично», «Только от главных файлов» или «Все связи» — по линиям бегут штрихи
  в направлении ссылки; цвет и скорость настраиваются.
- **Рост дерева при открытии** — узлы вырастают из центра ветка за веткой, уровень за уровнем.
- **Заморозить граф** — когда узлы улягутся, они перестают двигаться (меньше нагрузка на телефон).
- **Производительность — 60 FPS.** Качество эффектов подстраивается само: если кадр рисуется дольше
  ~6 мс или частота падает ниже 50 FPS, снижается разрешение слоя эффектов и детализация (меньше лучей,
  без боковых разрядов молний); когда запас появляется — качество возвращается. На телефоне старт
  со среднего качества. Кадры, в которых нечего рисовать, пропускаются. Опция **«Показывать FPS»**
  выводит счётчик кадров и текущее качество в углу графа.
- Всё отключается общим переключателем «Анимации». Системное «Уменьшить движение» (в Windows —
  выключенные «Эффекты анимации») учитывается, только если включить «Учитывать системное «Уменьшить движение»».
- **Не видно эффектов?** Команда «ObsOrg: Граф: проверить, почему не видно эффектов» покажет, что включено,
  нашёлся ли граф, сколько в нём главных файлов (кольца и лучи идут от них) и рисуются ли кадры.

## Граф: модули

**Модуль** — барьер вокруг группы заметок в графе. Группа задаётся **папкой** (все файлы в ней,
включая подпапки) или **тегом**. В модуль попадают и **ещё не созданные заметки**, на которые
ссылаются его заметки через `[[…]]` (в графе они видны как отдельные точки).

- **Граница** своего цвета: «Облако» (повторяет форму группы) или «Круг»; расширяется вместе с числом
  заметок (√n, общий масштаб настраивается). Внутри — лёгкая заливка, сверху — подпись «Название · N».
- **Линия границы** — по умолчанию **зигзаг**; ещё: сплошная, пунктир, точки, волна, двойная, электрическая.
  Задаётся для всех сразу или для каждого модуля отдельно; зубцы, штрихи и волна медленно ползут
  вдоль границы (отключается).
- **У каждого модуля своё место**: модули не заходят друг в друга — их раздвигает, пока барьеры
  не перестанут пересекаться (стоять вплотную можно, зазор настраивается). Место под модуль считается
  по реальному размеру скопления его заметок. На месте модуля закрепляется одна точка — его главный
  файл (или вся ветка дерева прокачки, сохраняя форму); остальные заметки связаны с ним и свободно
  плавают вокруг. Вырос модуль и упёрся в соседа — соседа плавно, с пружинкой, отталкивает.
- **Твёрдые барьеры** (по умолчанию включены): заметки модуля не выходят за его барьер, чужие — не заходят
  внутрь. Нарушителя ставит на край и сразу отпускает, так что он продолжает плавать. Если физика
  упорно тянет заметку сквозь стенку (связь с другим модулем), через несколько секунд она остаётся
  прижатой к стенке, а граф успокаивается — без постоянной нагрузки. Прижатые заметки отпускаются,
  когда раскладка меняется.
- **Заметка — только в одном модуле**, самом конкретном: модуль подпапки забирает свои заметки
  у модуля папки (например, «Меню/Десерты» отдельно от «Меню»), модуль по тегу важнее модуля по папке.
- **Окраска точек** в цвет модуля — по желанию, для каждого модуля отдельно (через родные цветовые
  группы графа; появляется после повторного открытия графа).
- **Появление**: «Пузырь» (барьер надувается из центра с упругим отскоком и колышется, потом
  успокаивается) или «Закрывается по кругу» (граница прорисовывается по часовой стрелке со светящейся
  точкой на конце). Граница плавно перетекает за заметками, пока граф раскладывается, — без рывков.
- Модули видны и при выключенных анимациях — тогда граница просто не двигается.

Создать модуль: правый клик по папке → **«Сделать модулем графа»**, команда
«ObsOrg: Граф: сделать папку текущей заметки модулем» или Настройки → «Граф: модули» → «Добавить модуль».

## Уровни веток

Каждая папка с главным файлом — ветка со своим уровнем.
**Опыт = слова во всех заметках ветки (включая подпапки) + 25 за каждую заметку.**
Уровни: 1 — 200 XP, 2 — 600, 3 — 1 200, 4 — 2 000, 5 — 3 000… (каждый следующий дороже).

- В начале списка главного файла — живая карточка: значок уровня, полоса опыта, сколько до следующего,
  число заметок и слов, ниже — подветки со своими уровнями. Карточка — это блок
  ```` ```folder-hub-level``` ````, который отрисовывается на лету, поэтому файл не переписывается
  при каждом сохранении (Syncthing не гоняет лишние изменения).
- В панели календаря — карточка «Ветки» со всеми ветками верхнего уровня; нажатие открывает главный файл.
- Ветка поднялась на уровень — уведомление «⬆ Ветка «Меню» достигла 4-го уровня!», значок в карточке
  подпрыгивает, а в графе от её главного файла расходится большая вспышка.
- При запуске плагин в фоне пересчитывает слова во всех заметках (по нескольку за раз, без подвисаний).

## Счётчик слов и календарь

Открывается значком 📅 на боковой ленте (на телефоне — в меню ленты) или командой
«Открыть календарь и счётчик слов». Панель встаёт в правую боковую колонку.

- **Сегодня:** кольцо прогресса к цели на день (по умолчанию 500 слов), сколько осталось,
  серия дней подряд 🔥, сколько слов удалено. Выполнили цель — кольцо зеленеет, летит конфетти
  и всплывает уведомление.
- **Последние 7 дней:** столбики по дням и пунктирная линия цели. Нажмите на столбик — откроется этот день.
- **Календарь месяца:** чем больше слов написано в день, тем насыщеннее ячейка. Точка в углу —
  есть заметка дня, точки снизу — сколько заметок создано в этот день. Нажатие выбирает день,
  повторное нажатие открывает заметку дня (или создаёт её по шаблону).
- **Карточка дня:** слова за день, кнопка «Открыть / Создать заметку дня», список созданных в этот день заметок.
- На компьютере в строке состояния внизу: `✍ 342 / 500`.

**Что считается.** Слова, которые вы пишете в заметке, открытой в редакторе: разница в числе слов
при каждом автосохранении. Свойства (frontmatter) и `%% комментарии %%` не считаются. Изменения от
синхронизации, других плагинов и обновления главных файлов папок не учитываются.

**Заметки дня.** Папка, формат имени и шаблон берутся из встроенного плагина «Ежедневные заметки»;
в настройках ObsOrg их можно переопределить. В шаблоне работают `{{date}}`, `{{date:DD.MM.YYYY}}`,
`{{time}}`, `{{title}}`. Если заметки дня лежат в папках по годам/месяцам, добавьте их папку в
«Исключённые папки», чтобы там не создавались главные файлы.

**Анимации** отключаются в настройках; если в системе включено «Уменьшить движение», они выключаются сами.

> Статистика хранится в `.obsidian/plugins/folder-hub/data.json` на каждом устройстве.
> Если вы синхронизируете настройки плагинов между устройствами, история одного устройства может
> перезаписать историю другого.

## Установка

### Из GitHub прямо в Obsidian (через BRAT) — удобнее всего, особенно на телефоне

1. Obsidian → Настройки → Сторонние плагины → выключите «Безопасный режим» → «Обзор» →
   найдите **BRAT** (Obsidian42 - BRAT) → «Установить» → «Включить».
2. Настройки BRAT → **Add beta plugin** → вставьте `SolivagusMinus/ObsidianOrgan` → **Add plugin**.
3. Включите **ObsOrg** в списке сторонних плагинов.

BRAT сам проверяет обновления: когда выходит новая версия, она ставится автоматически
(или командой «BRAT: Check for updates»). Репозиторий должен быть публичным — для приватного
в настройках BRAT нужно указать GitHub-токен с доступом на чтение.

Релизы собираются автоматически (`.github/workflows/release.yml`): при каждом изменении версии
в `manifest.json` на основной ветке репозитория GitHub собирает плагин, прогоняет тесты и публикует релиз
с файлами `main.js`, `manifest.json`, `styles.css`.
Чтобы выпустить новую версию, поднимите `version` в `manifest.json`, `package.json`
и добавьте строку в `versions.json`.

### Вручную

1. В хранилище создайте папку `.obsidian/plugins/folder-hub/`
   (папка `.obsidian` скрытая — включите показ скрытых файлов).
2. Положите туда три файла из этого репозитория: `main.js`, `manifest.json`, `styles.css`.
3. Obsidian → Настройки → Сторонние плагины → отключите «Безопасный режим» →
   нажмите «Обновить» → включите **ObsOrg**.

Для уже существующих папок: команда «Создать главные файлы во всех папках хранилища»
или правый клик по папке → «Создать главный файл папки».

### Цвет в графе
Настройки плагина → «Цвет в графе» → «Добавить в граф», затем закройте и откройте граф.
Вручную: Граф → ⚙ → Группы → Новая группа → запрос `tag:#folder-index` → выбрать цвет.

Все команды собраны в палитре команд (Ctrl/Cmd+P) под именем **ObsOrg** — наберите «ObsOrg», чтобы увидеть их все.

| --- | --- |

| ObsOrg: Папки: сделать текущую заметку главным файлом папки | |
| ObsOrg: Папки: создать главные файлы во всех папках хранилища | для папок, где его ещё нет |
| ObsOrg: Папки: обновить все главные файлы | досинхронизировать списки |
| ObsOrg: Папки: перестроить все главные файлы заново | применить новую раскладку/сортировку, сбросив правки *внутри* блока |
| ObsOrg: Граф: включить/выключить дерево прокачки | |

В контекстном меню заметки: «Сделать главным файлом папки» / «Перестать быть главным файлом».

## Шаблон нового главного файла (по умолчанию)

```markdown
---
tags:
  - {{tag}}
folder-index: true
cssclasses:
  - folder-hub-index
---

{{list}}
```

`{{list}}` — место для списка ссылок, `{{folder}}` — имя папки, `{{tag}}` — тег, `{{date}}` — дата.
Свойство `folder-index: true` помогает плагину узнавать главный файл, даже если его переименовали вручную.

## Почему не Dataview

Запрос Dataview `LIST FROM "Меню"` показывает файлы, но **в графе связей не появится**:
граф строится только по настоящим ссылкам `[[…]]`, записанным в текст заметки.
ObsOrg пишет именно настоящие ссылки.

## Замечания

- Если пользуетесь синхронизацией (Obsidian Sync, git, Syncthing) на нескольких устройствах,
  включите плагин везде одинаково: плагин ждёт ~1 с после появления папки и не создаёт
  второй главный файл, если первый уже приехал через синхронизацию.
- Служебные папки (шаблоны, вложения) добавьте в «Исключённые папки».

## Разработка

```bash
npm install
npm run build   # проверка типов + сборка main.js
npm test        # юнит-тесты (список ссылок, подсчёт слов, серии, раскладка веток, уровни)
npm run dev     # сборка с отслеживанием изменений
```
