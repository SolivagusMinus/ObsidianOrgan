# Folder Hub — плагин для Obsidian

Главные файлы папок со ссылками для графа + граф «дерево прокачки» + счётчик слов за день + календарь с анимациями.

Создаёте папку `Меню` — внутри сразу появляется файл `Меню.md`.
Кидаете в папку любой файл — в `Меню.md` добавляется ссылка `[[файл]]`.
Удаляете или переносите файл — ссылка исчезает. В графе все файлы папки
связаны со своим главным файлом, а через главные файлы подпапок получается дерево:

```
Меню ── Суп
  │ ─── Салат
  └──── Десерты ── Торт
                └─ Мороженое
```

## Что умеет

- **Автосоздание.** Новая папка → главный файл с тем же именем (имя настраивается: `{{folder}}`, `_{{folder}}`, `{{folder}} (оглавление)`…).
- **Автосписок ссылок** на все файлы папки: заметки, картинки, PDF, canvas (можно ограничить только `.md` или исключить расширения).
- **Раскладки:** столбик (маркированный список), нумерованный список, таблица в 1–6 колонок, свой шаблон строки
  (например `- [ ] {{link}} — {{ctime}}`).
- **Главный файл можно редактировать.** Плагин трогает только блок между
  `%% folder-hub:start %%` и `%% folder-hub:end %%` (в режиме чтения эти метки не видны).
  Всё выше и ниже — ваше. А с включённой опцией «Сохранять ручные правки» можно и внутри
  списка менять порядок строк, дописывать пояснения рядом со ссылками, вставлять подзаголовки —
  плагин лишь допишет новые файлы в конец и уберёт строки удалённых.
- **Связь с подпапками:** в главный файл попадает ссылка на главный файл каждой подпапки.
- **Выделение:** главный файл в проводнике окрашивается выбранным цветом, получает значок (★ по умолчанию)
  и жирный шрифт; заголовок самой заметки тоже окрашен. По желанию подкрашиваются и папки.
- **Цвет в графе:** главные файлы получают тег `#folder-index`; кнопка «Цвет в графе» в настройках выделяет их в графе цветом.
- Переименовали папку — главный файл переименуется следом (ссылки на него обновятся).
- При запуске Obsidian списки сверяются с реальным содержимым папок (если файлы добавляли
  через проводник ОС, пока Obsidian был закрыт).

## Граф: дерево прокачки

Каждая папка верхнего уровня — **ветка**, которая растёт в свою сторону, как ветки навыков в играх.
Главные файлы папок закрепляются узлами вдоль своей ветки (подпапки — дальше от центра),
а обычные файлы висят на них листьями и живо покачиваются.

- **Форма:** «Звезда» — ветки расходятся во все стороны; «Дерево прокачки» — ветки стоят рядом и растут вверх.
- **Направление каждой ветки** можно задать вручную (↑ ↗ → ↘ ↓ ↙ ← ↖) или оставить «Авто» —
  тогда ветки займут свободные стороны, крупным достанется больше места.
- **Длина ветки** и **ширина веера** — ползунками; **«Закреплять и файлы»** — выстроить файлы аккуратным веером.
- Команда: «Граф: включить/выключить дерево прокачки».

> Раскладка использует внутренний механизм графа Obsidian (тот же, которым граф закрепляет узел,
> пока вы его тащите). Официального API для этого нет, поэтому после обновления Obsidian эффект может
> перестать работать — заметкам это ничем не грозит, тогда просто выключите опцию и напишите, обновим плагин.
> Работает в глобальном графе; локальный граф не меняется.

## Счётчик слов и календарь

Открывается значком 📅 на боковой ленте (на телефоне — в меню ленты) или командой
«Открыть календарь и счётчик слов». Панель встаёт в правую боковую колонку.

- **Сегодня:** кольцо прогресса к цели на день (по умолчанию 500 слов), сколько осталось,
  серия дней подряд 🔥, сколько слов удалено. Выполнили цель — кольцо зеленеет, летит конфетти
  и всплывает уведомление.
- **Последние 7 дней:** столбики по дням и пунктирная линия цели. Нажмите на столбик — откроется этот день.
- **Календарь месяца:** чем больше слов написано в день, тем насыщеннее ячейка. Точка в углу —
  есть заметка дня, точки снизу — сколько заметок создано в этот день. Нажатие выбирает день,
  повторное нажатие открывает заметку дня (или создаёт её по шаблону).
- **Карточка дня:** слова за день, кнопка «Открыть / Создать заметку дня», список созданных в этот день заметок.
- На компьютере в строке состояния внизу: `✍ 342 / 500`.

**Что считается.** Слова, которые вы пишете в заметке, открытой в редакторе: разница в числе слов
при каждом автосохранении. Свойства (frontmatter) и `%% комментарии %%` не считаются. Изменения от
синхронизации, других плагинов и обновления главных файлов папок не учитываются.

**Заметки дня.** Папка, формат имени и шаблон берутся из встроенного плагина «Ежедневные заметки»;
в настройках Folder Hub их можно переопределить. В шаблоне работают `{{date}}`, `{{date:DD.MM.YYYY}}`,
`{{time}}`, `{{title}}`. Если заметки дня лежат в папках по годам/месяцам, добавьте их папку в
«Исключённые папки», чтобы там не создавались главные файлы.

**Анимации** отключаются в настройках; если в системе включено «Уменьшить движение», они выключаются сами.

> Статистика хранится в `.obsidian/plugins/folder-hub/data.json` на каждом устройстве.
> Если вы синхронизируете настройки плагинов между устройствами, история одного устройства может
> перезаписать историю другого.

## Установка

1. В хранилище создайте папку `.obsidian/plugins/folder-hub/`
   (папка `.obsidian` скрытая — включите показ скрытых файлов).
2. Положите туда три файла из этого репозитория: `main.js`, `manifest.json`, `styles.css`.
3. Obsidian → Настройки → Сторонние плагины → отключите «Безопасный режим» →
   нажмите «Обновить» → включите **Folder Hub**.

Для уже существующих папок: команда «Создать главные файлы во всех папках хранилища»
или правый клик по папке → «Создать главный файл папки».

### Цвет в графе
Настройки плагина → «Цвет в графе» → «Добавить в граф», затем закройте и откройте граф.
Вручную: Граф → ⚙ → Группы → Новая группа → запрос `tag:#folder-index` → выбрать цвет.

| Команда | Что делает |
| --- | --- |
| Создать/обновить главный файл в папке текущей заметки | |
| Открыть главный файл текущей папки | |
| Создать главные файлы во всех папках хранилища | для папок, где его ещё нет |

| Перестроить все главные файлы заново | применить новую раскладку/сортировку, сбросив правки *внутри* блока |

В контекстном меню папки: «Создать / Открыть / Обновить главный файл папки».

## Шаблон нового главного файла (по умолчанию)

```markdown
---
tags:
  - {{tag}}
folder-index: true
cssclasses:
  - folder-hub-index
---

{{list}}
```

`{{list}}` — место для списка ссылок, `{{folder}}` — имя папки, `{{tag}}` — тег, `{{date}}` — дата.
Свойство `folder-index: true` помогает плагину узнавать главный файл, даже если его переименовали вручную.

## Почему не Dataview

Запрос Dataview `LIST FROM "Меню"` показывает файлы, но **в графе связей не появится**:
граф строится только по настоящим ссылкам `[[…]]`, записанным в текст заметки.
Folder Hub пишет именно настоящие ссылки.

## Замечания

- Если пользуетесь синхронизацией (Obsidian Sync, git, Syncthing) на нескольких устройствах,
  включите плагин везде одинаково: плагин ждёт ~1 с после появления папки и не создаёт
  второй главный файл, если первый уже приехал через синхронизацию.
- Служебные папки (шаблоны, вложения) добавьте в «Исключённые папки».

## Разработка

```bash
npm install
npm run build   # проверка типов + сборка main.js
npm test        # юнит-тесты (список ссылок, подсчёт слов, серии, раскладка веток)
npm run dev     # сборка с отслеживанием изменений
```
